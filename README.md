# LiveData AR

Panel de audiencias de los vivos de YouTube de canales argentinos.

- **Panel:** https://jro-ar.github.io/livedata-ar/
- **Recolector:** `.github/workflows/recolector.yml` toma una muestra cada 10 minutos y guarda todo en la rama `datos`.
- **Canales seguidos:** `canales.json` (para sumar un canal, agregar una línea con su @ y su categoría).
